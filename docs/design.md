# Оформление дашборда — план (раздел 9.3 SPEC)

Предметная рамка: рабочий инструмент, открытый на втором мониторе в час ночи, когда
25 человек ждут решения по луту. Плотность важнее воздуха, читаемость с расстояния
важнее изящества, анимаций появления нет.

## Главная задача — девять классовых цветов, которые не превращаются в кашу

Классовые цвета WoW обязательны (готовый словарь, читается мгновенно), но 9 насыщенных
цветов на экране — это каша, если заливать ими плашки. Решение осознанное:

- **Классовый цвет — точечный акцент, не заливка.** Он живёт только в двух местах на
  строку: имя игрока (текст цветом класса) и тонкая линейка 3px слева от строки.
  Всё остальное — нейтральные чернила. 25 строк девяти цветов читаются как
  упорядоченный реестр, а не конфетти.
- **Пол под цветом нейтральный тёмный** (тёплый графит `#16161a`), низкая насыщенность,
  чтобы классовые цвета звучали, а не спорили с фоном.
- **Контраст-флор.** Тёмные классовые цвета (шаман `0070DD`, рыцарь смерти, чернокнижник)
  на тёмном фоне не проходят по AA — цвет автоматически осветляется в коде до контраста
  ≥ 4.5:1. Никогда не рисуем нечитаемое имя.

Тёмная тема здесь — сознательный выбор (тёмная комната, второй монитор, плотные данные,
меньше слепящего света), а не дефолт. Светлая тема подхватывается через
`prefers-color-scheme` как бонус.

## Типографика

- Системный шрифт для интерфейса, `tabular-nums` для всех чисел — колонки выравниваются.
- База 13px, плотные строки таблиц ~30px. Заголовки скромные, без гигантизма.

## Сетка

- Верхняя навигация из пяти экранов, липкий заголовок таблиц, сортировка по любой колонке.
- Таблицы работают при 40+ игроках без пагинации; на телефоне уезжают в горизонтальный скролл.

## Чего избегаем (выдаёт сгенерённую страницу)

- Одинаковых скруглённых карточек с одинаковой тенью → плоские панели с волосяной рамкой,
  различаются содержимым, а не одинаковым хромом.
- Разреженных ALL-CAPS подписей над каждым заголовком → нет.
- Стрелок в конце ссылок, градиентов-украшений → нет.

## Обязательный минимум

Работает на телефоне, видимая фокусировка с клавиатуры, уважение к
`prefers-reduced-motion`, контраст AA.
